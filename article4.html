Список терминов.

Java
язык программирования, главным архитектором которого был Гослинг. Задумывался как простой, надёжный и переносимый язык для широкого круга устройств.
JVM (Java Virtual Machine)
виртуальная машина Java. Это среда, в которой выполняется байт‑код Java. Именно JVM обеспечивает принцип «напиши один раз — запускай везде»: один и тот же код работает на разных платформах.
Байт‑код (bytecode)
промежуточное представление программы, которое генерирует компилятор Java. Байт‑код не зависит от процессора и ОС: его исполняет JVM.
Write Once, Run Anywhere (WORA)
ключевой девиз и философия Java, которую продвигал Гослинг: код пишется один раз и может запускаться на любой платформе, где есть совместимая JVM.
Green Project
внутренний проект в Sun Microsystems, в рамках которого разрабатывали технологии для «умных» устройств. Именно в нём родилась идея и первые версии Java.
Star7
прототип устройства (гаджет с цветным сенсорным экраном), созданный в рамках Green Project. На нём демонстрировали возможности Java и показывали, что язык подходит даже для устройств с ограниченными ресурсами.
NeWS (Networked Extensible Window System)
графическая оконная система на базе PostScript, одним из создателей которой был Гослинг. Идея состояла в переносимых, сетевых графических интерфейсах; NeWS повлияла на представления о клиент‑серверной графике, хотя и не стала массовой.
Объектно‑ориентированное программирование (ООП)
парадигма, на которой построен Java. Гослинг сознательно делал упор на объекты, инкапсуляцию и повторное использование кода, чтобы упростить поддержку больших систем.
